# Basics

- Authentication(first line of defense): The security process of verifying the identity of a user, device, or system, ensuring they are who they claim to be before granting access to resources.

- Authorization: The security process of granting an authenticated user or entity specific permissions to access resources, such as data, applications, or physical locations


# Service IAM

- IAM solves Authentication & Authorization in AWS.

# Contents

- Users(Authentication), Policies(Authorization/permissions) and groups(Attaching multiple users with Authentication+Authorization in a group to grant access to a set of services)

- Roles: AWS IAM roles are secure, temporary security credentials assigned to trusted users, applications, or AWS services (like EC2 or Lambda) to perform actions without using permanent access keys.
